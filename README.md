# JayJaydroid Modern Portfolio

A modern portfolio inspired by the uploaded reference:
- off-white page background
- large dark rounded portfolio card
- floating logo card
- minimalist navigation
- oversized hero typography
- profile image on the right
- project list
- skills/about section
- contact section
- responsive mobile layout

## Files

- index.html
- style.css
- script.js

## Profile photo

Place your photo in the same folder and name it:

1.jpg

The HTML already uses:

<img src="1.jpg" ...>

For a transparent cutout look similar to the reference, use a PNG/WebP image with the background removed. A normal JPG will still work.
